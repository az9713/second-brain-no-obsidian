# Semantic Graph Import

## Summary

Semantic graph import is the pattern of using a tool such as Graphify to extract concept nodes, relationships, communities, and source anchors from a corpus, then importing the result into a Markdown vault as a navigable map for an agent.

## Source-Backed Claims

- [Chase AI - Graphify + Obsidian](../sources/2026-06-08-chase-ai-graphify-obsidian.md) distinguishes Graphify from Obsidian's built-in graph: Graphify manufactures a semantic map from a repo or document corpus, while Obsidian mostly displays links that already exist between Markdown files.
- The same source says the demo generated concept nodes from Claude Code documentation rather than treating each document as a graph node.
- Chase describes Obsidian as the host environment and Graphify as the graph generator: Graphify can create Markdown concept stubs and backlinks, then the vault can place those files inside a larger project context.
- The source recommends wiring concept nodes back to source documents so an agent can move from concept node to related concepts to source document before answering.
- The source lists four ways to handle the volume of generated Markdown: keep a standalone vault, import a quarantined subfolder, selectively harvest pages, or redistribute pages into the main vault.

## Interpretation

For this second brain, semantic graph import should be treated as a processing mode, not as raw capture. The safest default is a quarantined import folder plus source-document wiring, followed by dream-sequence folding into durable concept pages. That preserves the benefit of a machine-generated map without letting hundreds of autogenerated stubs become unreviewed wiki truth.

This pattern also clarifies a difference between a Markdown wiki and a knowledge graph. A Markdown wiki is the durable compiled memory. A semantic graph import is a temporary or semi-durable map that helps decide what should become part of that memory.

## Contradictions or Tensions

- No factual contradiction recorded. There is an operational tension: large autogenerated graph imports improve discovery but can pollute a curated vault if imported without quarantine and source wiring.
