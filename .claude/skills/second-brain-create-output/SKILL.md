# create-output

Use this workflow when creating an artifact from the second brain.

## Protocol

1. Start with `wiki/index.md`.
2. Read relevant concept and source pages.
3. Verify critical claims against raw sources.
4. Create the artifact under the appropriate `outputs/` subfolder.
5. Append the artifact to `wiki/log.md`.

## Output Types

- Briefs: `outputs/briefs/`
- Memos: `outputs/memos/`
- Reports: `outputs/reports/`
