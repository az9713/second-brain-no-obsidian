# query-wiki

Use this workflow when answering questions from the second brain.

## Protocol

1. Start with `wiki/index.md`.
2. Identify relevant source pages and concept pages.
3. Read wiki pages first.
4. Read raw sources only when the answer needs verification, exact wording, or additional detail.
5. Answer with source-backed facts, interpretation, uncertainty, contradictions, and suggested next sources when useful.

## Output Standard

Do not present GPT 5.5 recommendations or local operating policy as Jay transcript claims. Label each clearly.
